# 작업에 무엇을 적어야 하나

A 에서 F 로 갈 때 중간의 B·C·D 도 적어야 하는가 — 아니다.

---

## 1. 짧은 답

**갈 곳만 적으면 RMF 가 길을 찾습니다.**

실제로 `대기3 → 대기4` 둘만 넣어 봤습니다. 어댑터가 받은 목적지는 이랬습니다.

```
넣은 것:   대기3 → 대기4
받은 것:   대기5 → 대기4 → 대기3 → 대기4
              ↑ 적지 않은 경유지
```

로봇이 충전1 쪽에 있었고, 거기서 대기3 으로 가려면 대기5·대기4 를 지나야
합니다. RMF 가 Lane 그래프를 보고 스스로 끼워 넣었습니다.

---

## 2. 다 적으면 오히려 손해다

`go_to_place` 를 나열하면 RMF 는 **적힌 순서를 반드시 지킵니다.** 그래서
되짚어 가는 일이 생깁니다.

연속 작업 1 이 그랬습니다. `픽업1 → 대기3 → 대기4 → 드랍오프1` 로 적어 두니

```
픽업1 → [대기4] → 대기3 → 대기4 → 드랍오프1
            ↑ 대기3 가려고 지남    ↑ 다시 돌아옴
```

**대기4 를 두 번 지납니다.** 대기3 을 굳이 적었기 때문입니다.

---

## 3. 적을 것과 안 적을 것

| 적는다 | 안 적는다 |
|---|---|
| 물건을 집는 곳 (픽업1) | 지나가기만 하는 곳 |
| 물건을 놓는 곳 (드랍오프1) | 대기 지점 (대기1~5) |
| 반드시 들러야 하는 곳 | 갈림길 |
| 기다려야 하는 곳 | 끝나고 돌아갈 자리 |

**대기 지점은 적지 마세요.** 그것은 RMF 가 교통 정리에 쓰는 자리입니다.
적어 두면 아무도 안 오는데 굳이 거기 가서 섭니다.

**끝나고 돌아가는 것도 적지 마세요.** 플릿 설정이 합니다.

```yaml
finishing_request: "park"
```

### 냉동주문처리를 줄이면

```
지금 (10단계)                  줄이면 (3단계)
  충전1 · 홈1 · 대기5 · 대기2     픽업1
  픽업1                          armLoad
  armLoad              →         드랍오프1
  대기3 · 대기4
  드랍오프1
  홈1
```

* **충전1** — 지금 서 있는 자리다. 갈 필요가 없다.
* **대기5·대기2·대기3·대기4** — 지나가는 길이다. RMF 가 알아서 지난다.
* **홈1** — `finishing_request: park` 가 한다.

**3단계로 줄여도 로봇은 똑같이 움직입니다.** 오히려 되짚어 가는 것이 없어져
더 빠릅니다.

---

## 4. 지나가는 것과 멈춰 서는 것은 다르다

```
경유    항상 일어난다    Lane 그래프에 길이 그렇게 나 있어서
대기    필요할 때만      다른 로봇을 비켜 줘야 할 때
```

충돌 위험이 없어도 **대기1 을 지나가기는 합니다** — 그쪽으로 Lane 이 나 있다면.
다만 **거기서 멈추지는 않습니다.**

대기 지점이 하는 일은 "여기서 서서 기다려라" 입니다. 그 자리가 필요 없으면
서지 않습니다.

### 한 대일 때는 교통 정리 자체가 없다

RMF 는 두 대 이상일 때 **Lane 을 시간까지 포함해 예약**합니다. "A 는 3~7초에
이 구간, B 는 그 뒤에" 하는 식입니다. 겹치면 뒤 로봇이 가까운 대기 지점에서
섭니다.

지금은 핑키 한 대라 예약할 상대가 없습니다. 그래서 늘 안 서고 갑니다.

## 5. "곧장 간다" 는 두 가지 뜻

| | 곧장 가나 |
|---|---|
| **어느 Waypoint 를 지나나** | ❌ Lane 그래프를 따른다 — 벽을 뚫고 못 간다 |
| **두 Waypoint 사이를 어떻게 가나** | ✅ Nav2 가 직선에 가깝게 간다 |

두 번째가 "레인 위로 안 간다" 는 그것입니다. **Nav2 는 Lane 을 모릅니다.**
점유격자 위에서 제 나름의 최단 경로를 만듭니다. 방이 트여 있으면 비스듬히
가로지릅니다.

실측 — 충전1 → 홈1 선을 따라 재 보니 좌우로 ±0.394m 가 전부 자유공간입니다.
벽이 없으니 Nav2 가 Lane 을 따라갈 이유가 없습니다.

```
큰 길      RMF 가 Lane 으로 정한다
그 안에서  Nav2 가 정한다
그 위에    교통 정리가 얹힌다
```

---

## 6. 언제는 다 적어야 하나

**순찰**처럼 특정 지점들을 반드시 순서대로 돌아야 할 때입니다. 그때는 도는
순서 자체가 일이므로 다 적는 것이 맞습니다.
