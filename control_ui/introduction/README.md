# 프로젝트 소개 자료

**스마트 팩토리를 위한 이기종 군집로봇 관제 시스템 개발** — 개발자 이광희

비전문가에게 이 프로젝트가 무엇인지 보여 주기 위한 자료입니다. 기종·시뮬레이터를
가리지 않는다는 점, 안전과 보안이 숫자로 박혀 있다는 점을 앞세웠습니다.

두 HTML은 **자립형**입니다. 서체·사진·동영상이 파일 안에 들어 있어 인터넷 없이
더블클릭만으로 열립니다. 그래서 `발표페이지.html`이 14.9MB입니다.

### 동영상이 왜 14.93초 · 10.6MB 인가

**길이** — 카톡 프로필 동영상 최대 길이가 15초입니다. 슬라이드당 정확히 5초로
하면 전환 시간이 붙어 15.6초가 되어 걸립니다. 그래서 4.93초씩으로 잡았습니다.

**용량** — 4K(3840×2160) · CRF 17 · 6.0Mbps 입니다. 화질을 올릴 때 CRF 를 더
내리면 11.7MB(CRF 16), 14.2MB(CRF 14)까지 갑니다. **CRF 17 을 고른 이유는
`발표페이지.html`이 아티팩트 한도 16MB 를 넘지 않아야 하기 때문입니다** —
동영상을 base64 로 심으면 4/3 배가 되어, 10.6MB 가 14.2MB 가 되고 페이지가
14.9MB 로 한도에 1.1MB 를 남깁니다. 페이지에 안 심을 거라면 CRF 를 14까지
내려도 됩니다.

## 다시 굽는 법

고칠 곳은 `src/deck.html`(발표 세 장)과 `src/wallpaper.html`(세로 배경화면)입니다.
나머지는 여기서 만들어집니다.

```bash
cd introduction/src

# 1. 사진을 슬라이드 크기로 줄여 images.json 으로 굽는다
python3 prep_images.py

# 2. 서체·사진을 심어 발표페이지.html 을 만든다
#    (동영상이 아직 없으면 내려받기 단추 없이 만들어진다)
python3 bake_deck.py

# 3. 세 장을 PNG 로 굽는다 — 조작줄은 #s1 로 얼어붙어 화면에 안 나온다
for n in 1 2 3; do
  google-chrome --headless=new --disable-gpu --hide-scrollbars \
    --force-device-scale-factor=2 --window-size=1920,1080 \
    --virtual-time-budget=6000 --screenshot=../"$n"장.png \
    "file://$PWD/../발표페이지.html#s$n"   # scale-factor 2 → 3840×2160
done

# 4. 동영상 — 5.3초짜리 세 장을 0.5초 페이드로 잇는다 (4K · CRF 17)
ffmpeg -y -loop 1 -t 5.3 -i ../1장-제목.png \
       -loop 1 -t 5.3 -i ../2장-구조.png \
       -loop 1 -t 5.3 -i ../3장-안전과보안.png \
  -filter_complex "[0][1]xfade=transition=fade:duration=0.5:offset=4.8[a];\
[a][2]xfade=transition=fade:duration=0.5:offset=9.6[v]" \
  -map "[v]" -r 30 -c:v libx264 -preset slow -crf 17 -g 30 -pix_fmt yuv420p \
  -profile:v high -level 5.1 -movflags +faststart ../포트폴리오-15초.mp4

# 5. 동영상이 생겼으니 다시 구워 내려받기 단추를 붙인다
python3 bake_deck.py

# 세로 배경화면은 따로 굽는다
python3 bake_fonts.py wallpaper.html ../배경화면페이지.html
```

3번과 5번 순서가 있는 이유는 **동영상이 슬라이드에서 나오고, 그 동영상이 다시
페이지 안으로 들어가기** 때문입니다. `bake_deck.py`는 동영상이 없으면 단추를
빼고 넘어가므로 첫 빌드에서 막히지 않습니다.

### 서체

나눔스퀘어 Bold(제목) · 나눔바른고딕(본문) · 나눔고딕코딩(표제란·수치)을 쓰고,
**실제로 쓰인 글자만 서브셋해 woff2 로 심습니다**(합계 119KB). 웹으로 띄울 때
폰트 CDN이 막혀 조용히 대체 서체로 떨어지는 것을 막기 위해서입니다.
빌드에는 `python3-fontTools`, `brotli`, `/usr/share/fonts/truetype/nanum` 이 필요합니다.

모노 서체에는 한글을 넣지 않습니다. 전각 자간이 벌어져 `즉 시  정 지` 처럼 한
낱말이 둘로 읽힙니다. 한글이 든 이름표는 `.chip` 클래스로 본문 서체를 씁니다.
