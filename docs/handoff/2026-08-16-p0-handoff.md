### 3.1 파이썬 실행 방법

이 저장소는 **두 종류의 파이썬**을 섞어 쓴다.

```bash
# ROS 가 필요한 것(control_tower, trihouse_*): 시스템 python3 + ROS
source /opt/ros/jazzy/setup.bash
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1     # 없으면 ROS launch 플러그인이 pytest 를 깨뜨림

# fms_gateway(FastAPI/pydantic/mysql): 별도 venv
/tmp/trihouse-task6-venv/bin/python
```

`fms_gateway` 의존성은 시스템 파이썬에 없다. 반대로 `rclpy` 는 venv 에 없다.
둘 다 필요할 때는 venv 의 `site-packages` 를 `PYTHONPATH` 에 얹는다:

```bash
export PYTHONPATH="/tmp/trihouse-task6-venv/lib/python3.12/site-packages:$PYTHONPATH"
```

> ⚠️ `/tmp` 는 재부팅하면 사라진다. venv 가 없어졌으면 다시 만들어야 한다:
> `python3 -m venv <경로> && <경로>/bin/pip install -r fms_gateway/requirements.txt`

### 3.2 MySQL 포트 세 개를 구분할 것

| 포트 | 용도 |
|---|---|
| `3306` | 기존 개발용 MySQL (이미 사용 중, 건드리지 말 것) |
| `3307` | **테스트 전용** — 통합 테스트가 스키마를 DROP/CREATE 한다 |
| `3308` | P0 compose 스택이 쓸 포트 (런북 기준) |

테스트 실행 시:

```bash

export FMS_DB_USER=fms_gateway FMS_DB_PASSWORD=test_gateway_password
export FMS_DB_DATABASE=trihouse_fms
```

## 4. 반드시 알아야 할 함정 4가지

### 4.1 좌표 원본 파일이 git 에 없다

```
control_system_test/rmf_control_ui/data/import/trihouse_test_01_physical_features.jsonl
```

이게 P0 의 **유일한 pose 출처**인데 `control_system_test/` 가 `.gitignore`
대상이다. 이번에 계획 Task 3 Step 4 가 요구한 표기 수정
(`source_radius_m` → `source_diameter_m`)을 적용했지만 **커밋에 담기지 않는다.**

새 환경에서 importer 가 `line 9: missing field source_diameter_m` 로 실패하면
런북 2.4 절의 보정 스크립트를 실행하면 된다.

### 4.2 `tools/` 디렉터리는 통째로 gitignore

계획은 `tools/measurement_gate.py` 를 만들라고 했지만 그 경로는 버전 관리가
안 된다. **`scripts/measurement_gate.py`** 로 옮겼다. 앞으로도 `tools/` 에
파일을 만들면 안 된다.

### 4.3 ROS 패키지의 namespace package 함정

ROS 패키지는 `<pkg>/<pkg>/` 구조라서 저장소 루트만 `sys.path` 에 넣으면
**바깥 디렉터리가 namespace package 로 먼저 잡혀** 실제 모듈을 못 찾는다.

- 테스트: 루트 `conftest.py` 가 안쪽 경로를 먼저 넣고 미리 import 해서 고정
- 기동 스크립트: `PYTHONPATH="$ROOT/trihouse_omx_adapter:$ROOT:..."` 순서가 중요

이 순서를 바꾸면 `python3 -m trihouse_omx_adapter.simulator_node` 가 깨진다.

### 4.4 관제 UI 는 Gateway 와 반드시 같은 origin

UI 는 Gateway 주소를 **페이지 origin** 에서 가져오고
(`GatewayClientConfiguration.resolve`), 다른 origin 은 HTTPS + credentialed
모드가 없으면 예외를 던진다. 그래서 `control_ui` 컨테이너의 nginx 가 `/api/`
와 운영 WebSocket 을 Gateway 로 reverse proxy 한다.

**브라우저는 `:3100` 만 본다. `:8080` 을 직접 열면 UI 가 깨진다.**
