2. 통신 시퀀스 다이어그램

LED 규칙은 세 상태만 사용합니다. OFF는 끄기, PERSON_DETECTED는 노란색, EMERGENCY는 빨간색입니다. 비상 상태가 사람 감지보다 항상 먼저 적용됩니다.
